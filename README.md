# 3D Cells

A 3D sketch I made in p5.js where five balls ("cells") float around inside an invisible sphere, bounce off the edge and bump into each other.

Live demo: https://aurangzeb002.github.io/p5js-3d-cells/

## What it does

- Each ball moves with its own speed and direction and drifts a little randomly
- Balls bounce back when they hit the edge of the sphere
- When two balls hit each other they push apart, swap speeds and change size slightly
- The light moves around the scene using sin and cos
- The balls use the colours of the Afghan flag (black, red and green)
- There's a small ball fixed in the middle as an extra

## Made with

JavaScript and p5.js (WEBGL mode)

## How to run

Download or clone the repo and open index.html in your browser.
